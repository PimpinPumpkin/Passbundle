Switch to PassBundle

Moving takes a few minutes: export from where your passwords are now, then import the file into PassBundle. PassBundle reads exports from about 70 apps.

Import into PassBundle

  1. Sign in to the web vault.
  2. Open Tools, then Import.
  3. Choose the app you're coming from under File format, choose the export file, and select Import.
  4. Delete the export file. It has your passwords in plain text.

To import into a business's shared collections, open the organization in the Admin Console, then Settings, Import.

From 1Password

  1. Open the 1Password app on your computer. Exports need the app, not the browser extension.
  2. Choose File, then Export, pick the account, and save it in the 1PUX format.
  3. In PassBundle, import it as 1Password (1pux/json).

Logins, notes, cards, identities, and their two-step login secrets come along. File attachments don't; save them from 1Password and add them again.

From Bitwarden

PassBundle is built on the same open-source apps, so everything in a Bitwarden export arrives exactly as it was, folders, custom fields, and two-step login secrets included.

  1. In Bitwarden's web vault, choose Tools, then Export vault, and pick .json. An encrypted export with a file password works too.
  2. In PassBundle, import it as Bitwarden (json).

Bitwarden's export doesn't include file attachments. Download them first and add them to the items again.

From LastPass

  1. In LastPass, open Advanced options and choose Export. LastPass asks for your master password and saves a CSV file.
  2. In PassBundle, import it as LastPass.

From your browser

  • Chrome: open Google Password Manager from the menu, then Settings, and choose Export passwords. Import as Chrome.
  • Edge: open Settings, then Passwords, and choose Export passwords from the menu beside your saved passwords. Import as Edge.
  • Firefox: open Passwords from the menu, then choose Export passwords from the menu at the top. Import as Firefox (csv).
  • Safari: on a Mac, open the Passwords app, then choose File, Export All Passwords. Import as Safari and macOS (csv).

Once your passwords are in PassBundle, turn off your browser's own password manager so the two don't both offer to save. Computers your organization set up with PassBundle have it turned off already.

From anything else

Look for an export option in your current app, then find it under File format in PassBundle: Dashlane, Keeper, Proton Pass, NordPass, Enpass, KeePass, and many more are there. If yours isn't, a CSV with a name, website, username, and password per line imports as Bitwarden (csv).
