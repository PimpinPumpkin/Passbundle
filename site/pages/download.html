Install the extension by hand

In Chrome, Edge, and other Chromium browsers:

  1. Download the zip and unzip it. Keep the folder: your browser loads PassBundle from it.
  2. Open the extensions page: chrome://extensions in Chrome, or edge://extensions in Edge.
  3. Turn on Developer mode.
  4. Choose Load unpacked, and pick the unzipped folder.
  5. Pin PassBundle to the toolbar from the extensions menu, and sign in.

It doesn't update itself. For a new version, put the new zip's files in the same folder, and choose Reload on PassBundle in the extensions page. Each release lists the zip's SHA-256.

Opening a test build

The apps are signed with PassBundle's own test keys, not yet by Apple or Microsoft, so the first time you open one, your device asks you to allow it:

  • Windows: choose More info, then Run anyway.
  • Mac: choose Open Anyway in System Settings, Privacy & Security.
  • Android: let your browser install apps when it asks.

Windows Hello unlock is in the Windows app, not yet tried on a real Windows Hello device. Touch ID unlock waits until the Mac app is signed by Apple. Each release lists its files' SHA-256.
