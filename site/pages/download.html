Get PassBundle

The app for your computer and phone, the browser extension, and the web vault. Your vault syncs between all of them.

PassBundle is in testing. The apps are test builds, the extension isn't in the browsers' stores yet, and our hosted service, vault.passbundle.com, opens at launch. Until then, PassBundle signs in to a server you run yourself: see Run your own server.

How to build and use it

No release yet. Until the first one, build it from its source code, as the guide shows.

Web vault

Your whole vault in any browser, on any computer, with nothing to install. Every PassBundle server has it, at the server's own address.

Ours, vault.passbundle.com, opens at launch.

These are test builds. They're signed with PassBundle's own test keys, not yet by Apple or Microsoft, so the first time you open one, your computer asks you to allow it: on Windows, choose More info, then Run anyway; on a Mac, choose Open Anyway in System Settings, Privacy & Security; on Android, let your browser install apps when it asks. Each release lists its files' SHA-256.

Then bring your passwords

Export them from your browser or your old password manager, and import the file into PassBundle. Most people are done in a few minutes.

Step-by-step guides for 1Password, LastPass, and every browser

Run your own server

PassBundle is open source. Run the server on your own hardware and point the apps at it: the sign-in screen asks where your vault is. It's in testing too: build the server and its web vault from the source code, as one container image (how).
