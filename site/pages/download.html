Install the extension by hand

In Chrome, Edge, Brave, and other Chromium browsers:

  1. Download the zip and unzip it. Keep the folder, because your browser loads PassBundle from it.
  2. Open the extensions page: chrome://extensions in Chrome, or edge://extensions in Edge.
  3. Turn on Developer mode.
  4. Choose Load unpacked, and pick the unzipped folder.
  5. Pin PassBundle to the toolbar from the extensions menu, and sign in.

It doesn't update itself. For a new version, put the new zip's files in the same folder, and choose Reload on PassBundle in the extensions page. Each release lists the zip's SHA-256.

Opening a test build

The apps are signed with PassBundle's own test keys, not yet by Apple or Microsoft, so the first time you open one, your device asks you to allow it:

  • Windows: choose More info, then Run anyway.
  • Mac: choose Open Anyway in System Settings, Privacy & Security.
  • Android: let your browser install apps when it asks.

Windows Hello unlock is in the Windows app, not yet tried on a real Windows Hello device. Touch ID unlock is in the Mac app, not yet tried on a real Mac with Touch ID; in the browser extension on a Mac, it waits until the app is signed by Apple. Each release lists its files' SHA-256.

Command line

The passbundle command is for IT scripts on Mac, Linux, and Windows. It signs in with an API key, reads the passwords your folders let you see, and makes items from templates.

Run your own server

PassBundle is free and open-source software. Run the server on your own hardware, and give the apps its address on the sign-in screen, which asks where your vault is. The server is in testing too, and you build it and its web vault from the source code as one container image (how).
