In development

Every client's passwords, run from one place.

PassBundle is a password manager built for managed service providers. One console for all of your clients, policies and templates that apply to every one of them, and end-to-end encryption that keeps each vault private, even from us.

Follow on GitHub What it does

Built for the way MSPs work

Your clients' people get a simple password manager. You get the tools to run dozens of them without signing in and out of each one.

Every client, one console

Members, pending approvals, expiring credentials, and weak or reused passwords for each client, side by side. Open any client's admin console in one click, with the same sign-in.

Default policies

Set your policies once and every client follows them, including clients you add later. A client that needs something different keeps its own setting.

Templates for every client

Make an item template once, for a firewall or a Microsoft 365 tenant, and every client has it. Edit it, and every copy changes.

Onboarding from your RMM

Each client gets an install command. Run it from your RMM: the extension installs, the browser's own password manager turns off, and people join the right client.

Access that fits your team

Limit a technician to chosen clients or to a helpdesk role. Give a client's point of contact just enough to manage their own people.

A record of everything

Every MSP action is logged with who did it, from where, and to which client. Clients see who from your team can reach them, and can remove you.

Private by design

End-to-end encrypted

Vaults are encrypted on people's own devices. The server stores only encrypted data and never holds a key that can open a vault, so neither we nor an attacker who reaches the server can read it.

Proven foundations

PassBundle is built on the open-source Bitwarden clients and Vaultwarden, two widely used projects. We follow their releases and their security fixes.

Open source

All of PassBundle's code is public, under the GPL and AGPL. Read it, check our work, or run your own server.
