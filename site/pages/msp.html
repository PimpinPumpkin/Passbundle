Questions

We're an internal IT team, not an MSP. Is this for us?

If you run IT for several companies, locations, or brands in one group, yes: each one is a client in the console, and they share one pool of seats. For a single company, see PassBundle for business.

What counts as a seat?

Each person in a client's organization, counted once a month. People who've been invited but haven't joined don't count, and neither do your own staff.

Which RMMs does the install command work with?

Any RMM that can run a PowerShell command as an administrator on Windows, such as NinjaOne, ConnectWise Automate, Datto RMM, and N-able. Intune and group policy work too.

Do clients need a domain, Active Directory, or an identity provider?

No. A client's people sign in with their own email address, on any domain, and a master password, so a five-person office with a workgroup and personal email addresses works as well as a company on Entra ID. Their computers don't need to be joined to a domain: the install command runs on any Windows computer your RMM reaches. Limiting a client's install command to its email domains is optional, and so is provisioning from Entra ID.

Do you work with Microsoft Entra ID?

Yes. Provisioning from Entra ID keeps each client's people and groups in step over SCIM, set up per client. Signing in with Entra, per client, is coming soon; at first, the master password still unlocks the vault.

Can we send events to our SIEM?

Yes. Send a client's events as they happen to Microsoft Sentinel, to syslog over TLS (JSON or CEF), or to a signed webhook, from Reporting, Event streaming in its admin console. Or add your SOC's tools in the MSP console, and they get every client's events, tagged with the client, and your own staff's activity, in one feed. Events never include item names, passwords, or anything else in a vault.

Can a client take its data with it?

Yes. A client's admins can export the organization's vault at any time, in a format other password managers import, and remove its MSP, which removes all of the MSP's staff at once.

Can we host it ourselves?

Yes. The server is open source and runs on your own hardware, with SQLite or PostgreSQL. What you pay us for is the hosted service: we run it, back it up, keep it updated, and answer when you need help.

Is there an API or PSA integration?

Not yet. Billing sync with ConnectWise, HaloPSA, and Autotask is planned, so seat counts flow into your invoices.
