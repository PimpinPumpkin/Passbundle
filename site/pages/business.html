Rollout

Set up every computer with one command.

Your organization's settings have an install command, under Joining and security. It's one line that runs our install script on a Windows or Linux computer, or makes a profile for your MDM on Macs. Run it from Intune, group policy, or any RMM.

  • Installs the extension in Chrome and Edge once it's in their stores, with your server already filled in
  • Turns off the browsers' own password managers, without deleting what's in them
  • Limit it to your email domains, so only your own people can use it
  • A whole office behind one internet connection can sign up at once

Microsoft Entra ID

People join and leave through Microsoft Entra ID.

Connect PassBundle to Microsoft Entra ID from your organization's settings. People you assign there are invited, people you turn off lose access, and Entra's groups become PassBundle groups with the same members.

  • Standard SCIM, set up in Entra in a few steps
  • Give a group a shared folder once, and everyone Entra adds to it gets it
  • Sign in with Entra is built, and not yet checked with a real Microsoft 365 tenant

Does it work on Macs?

Yes. The extension and the web vault work on Mac, Windows, and Linux, and there are test builds of the PassBundle app for all three. The install command in your settings comes for Windows, Linux, and Mac, where it makes a profile for your MDM and a second line installs the app; the scripts are in our repository. Windows Hello unlock is built, not yet tried on a real Windows Hello device; Touch ID waits until the app is signed by Apple.

Is there an app for phones?

On Android, yes. A test build fills passwords in apps and browsers and unlocks with your fingerprint or face. The iPhone app is coming. Until then, people can open the web vault in their phone's browser.

Do we need a domain, Active Directory, or an identity provider?

No. People sign in with their own email address, on any domain, and a master password. You don't need a domain controller, Active Directory, Microsoft Entra ID, Google Workspace, or single sign-on, and your computers don't need to be joined to a domain. The install command works on any Windows computer you can run a PowerShell line on as an administrator, by hand or from your RMM. Limiting the install command to your email domains is optional, and so is Entra ID.

Do you support single sign-on or directory sync?

Directory sync, yes. Provisioning from Microsoft Entra ID adds, updates, and removes people and groups for you. Signing in with Entra is built too. Neither has been checked with a real Microsoft 365 tenant yet. Signing in with Entra doesn't replace the master password, which still unlocks the vault.

Can we move from another password manager?

Yes. Import a shared export into your organization's folders, and each person brings their own passwords. See Switch to PassBundle.
