Rollout

Your organization's Settings page has an install command: one PowerShell line that sets up a Windows computer. Run it from Intune, group policy, or any RMM.

  • Installs the extension in Chrome and Edge, with your server already filled in

Does it work on Macs?

Yes. The extension and the web vault work on Mac, Windows, and Linux, and there are test builds of the PassBundle app for all three. The rollout command and Windows Hello unlock are for Windows today; Mac rollout and Touch ID are next.

Is there an app for phones?

Android, yes: a test build that fills passwords in apps and browsers and unlocks with your fingerprint or face. The iPhone app is coming. Until then, people can open the web vault in their phone's browser.

Do you support single sign-on or directory sync?

Directory sync, yes: provisioning from Microsoft Entra ID adds, updates, and removes people and groups for you. Signing in with Entra is coming soon; until then, people sign in with their own master password.

Can we move from another password manager?

Yes. Import a shared export into your organization's folders, and each person brings their own passwords. See Switch to PassBundle.
