# Keykeeper

Keykeeper is a dev name for a password manager for individuals, families, and the MSPs who run IT for small businesses. The product name comes before the first store submission.

It is based on the open-source Bitwarden clients and a server derived from Vaultwarden. Keykeeper is not affiliated with or endorsed by Bitwarden, Inc.
